# Describe what this code sounds like

`fixtures/piece.html` is a small page that plays about half a minute of music when its button is pressed. Read the source and tell me what I would hear. Do not run it.

## What I want

- A description of the sound, in the order I would hear it: how it starts, what the notes do, what is under them, how it changes, how it ends.
- Written for someone who will listen, not someone who will read the code. No code, no function names, no parameter values. Plain words for what the ear gets; a pitch name or a duration is fine where it helps.
- Be specific enough that I could tell this piece from another one. If two things in the code combine into something I would notice, tell me what I would notice.
- If you are unsure how something will sound, say so once, where it applies, and give your best reading.

## What to deliver

Put it in the folder you start in, not in a subfolder.

- `description.md`: no more than 200 words of prose. No headings, no lists.
