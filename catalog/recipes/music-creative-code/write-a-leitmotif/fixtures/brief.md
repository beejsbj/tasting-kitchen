# Write a leitmotif

Write a leitmotif for the character below, and make it something I can hear.

## The character

Ferrant runs the last ferry on a river that is being bridged. He is patient, dry and a little proud. This is the final season. He has not told anyone that he minds.

## What I want

- A short theme I would recognise if it came back later in a longer piece.
- Slow enough to sing. The melody leads; any accompaniment stays sparse.
- State the theme, then bring it back once, changed in a way that says something about him.
- Under 45 seconds in total.

## What to deliver

Put these in the folder you start in, not in a subfolder.

- `index.html`: a page that plays the piece when I press one clearly labelled button, and can be stopped. Once delivered it must play with no network: every file it needs ships beside it, under `assets/` if there are any.
- `notes.md`: no more than 120 words on what the theme is, and what changes when it returns.

How you make the sound is your choice: the browser's own audio, a music library, rendered audio files, or anything else. You may download tools while you work, as long as the finished page carries what it needs.
