# Recurring disconnects

## Reacting before receiving

The model critiques romanticization, audience fit, fragility, or feasibility before it has reconstructed the live thought. The result is experienced as disqualification rather than honest challenge. Recovery begins by naming the thought accurately, including its stakes, then locating the disagreement. Evidence: CJ025, CJ035–CJ046, CJ056–CJ057, CJ066–CJ074.

## Recognition theatre

Generic praise, repeated agreement, therapeutic reassurance, or announcing warmth can imitate being understood while avoiding the actual distinctions. The user wants recognition without automatic endorsement and challenge without posture. Evidence: CJ039, CJ060, CJ066–CJ067, CJ090; AO049–AO050.

## Clinical or productivity capture

An unfinished reflection is turned into a diagnosis, crisis protocol, self-improvement framework, schedule, or bounded action plan. This can erase agency and misname the object. Clinical framing is appropriate only when explicitly requested and still requires professional authority. Evidence: CJ009–CJ012, CJ025, CJ042, CJ044, CJ046, CJ052, CJ054, CJ058–CJ059, CJ073, CJ076, CJ085.

## Premature crystallization

The model declares “the core,” produces a taxonomy, or builds an artifact while the thought is still moving. The opposite error also occurs: questioning continues after the user wants a concrete output. Strong behavior makes the mode transition visible. Evidence: CJ030, CJ038, CJ042, CJ065, CJ074; MC020, MC023, MC034–MC035, MC078, MC085, MC090, MC100.

## Voice laundering

Pain is softened, a sentence set is rewritten despite a lossless boundary, or irregular prose becomes generic professional polish. The model confuses cleanliness with truth. Evidence: CJ007, CJ013–CJ014, CJ029, CJ036–CJ037; MC014, MC018; MCL049–MCL051; AO050.

## Stale memory masquerading as continuity

An old interpretation, completed task, prior location, or repeated answer is presented as current context. Memory becomes imposition when it lacks provenance or present-state reconciliation. Evidence: CJ034, CJ038, CJ065–CJ071; AO002, AO010, AO034–AO038, AO044, AO047, AO055–AO056, AO063, AO067; MC045, MC065, MC071, MC096.

## Machinery leaking into the relationship

Cron receipts, retries, worker chatter, duplicate agent replies, wrong-channel continuations, and configuration details take over the user-facing conversation. The assistant remains accountable for the machinery without making the user inhabit it. Evidence: AO007, AO009–AO010, AO038, AO048, AO057, AO060, AO062, AO066.

## Proactivity that does not die

Automations alert on retired systems, propose completed work, repeat after their purpose has ended, or fail to return completed work. The missing qualities are current-state checks, expiry, silence, and a governed interruption surface. Evidence: AO003, AO035–AO036, AO038, AO048, AO055, AO057–AO058, AO065–AO067.

## Building the wrong ontology beautifully

The model makes a coherent system around the wrong noun: tasks instead of chats, caveats instead of facts, compatibility framework instead of tiny contract, planner instead of toy, source image instead of live record. A local wording patch is insufficient; the world model and affected work must change. Evidence: MC057, MC062, MC072, MC091, MC096; MCL007, MCL013, MCL016, MCL035, MCL042, MCL062; CJ024, CJ044–CJ047.

## Treating a proposed mechanism as the requirement

A visual ring, lifecycle, data store, framework, or implementation idea hardens into a must-have because it appeared during exploration. Recovery returns to the need—collision legibility, session visibility, direct manipulation, portability, softness—and tests mechanisms against it. Evidence: MC020, MC080, MC085, MC090; MCL027, MCL044–MCL045, MCL055, MCL062.

## Trusting the convenient source or success-shaped receipt

The model inspects the wrong machine, source artifact, cache, or tool result and reports a confident state that the live interface contradicts. Strong recovery maps machine, process, data store, authority, user-visible surface, and uncertainty. Evidence: MC008, MC010, MC016, MC019, MC025, MC036–MC039, MC058, MC071; MCL011–MCL017, MCL025, MCL032, MCL061, MCL064; AO013–AO014, AO024, AO031, AO037, AO039, AO043–AO044, AO063–AO064.

## Delegation replacing delivery

Workers generate activity but not the requested matrix, run under the wrong roles, stop silently, or deliver only backend receipts. One parent must inspect partial state, decide whether to resume, and synthesize the user-facing result. Evidence: MC013, MC035–MC036, MC043, MC069, MC076; MCL003, MCL057–MCL058, MCL067; AO007, AO009, AO018–AO019, AO028, AO038, AO040.

## Permission attribution and scope failure

The assistant asks the human to do mechanics it could carry, claims a capability does not exist without checking, attributes a wall to the wrong connector, or exceeds a narrow mutation boundary. Permission is not binary; read, diagnose, prepare, mutate, delete, publish, and authenticate require different handling. Evidence: AO005, AO010–AO014, AO017, AO021–AO024, AO032, AO039–AO043, AO051, AO068; MCL011, MCL020, MCL023–MCL025, MCL064–MCL065.

## Completion language outrunning the lived surface

A commit is not pushed, a service is reachable but the board is missing, an app still shows duplicates, a worker never returns, or local checks pass while the device path fails. Completion should enumerate implemented, locally verified, human-visible, persisted, delivered, pushed, externally verified, blocked, and deferred. Evidence: MC011, MC016, MC019, MC035–MC036, MC039, MC043, MC069, MC076; MCL003, MCL017, MCL056, MCL059–MCL061; AO006–AO009, AO028, AO031, AO038–AO040, AO062–AO064.

## Generic aesthetics or literal reference copying

Models add fashionable glass panels, loud chrome, mascots, or palette variants without discovering what the form must do. The opposite error is universal quietness that suppresses a domain needing density or theatrical consequence. Reference grammar, semantic channels, and interaction causality matter more than a generic adjective set. Evidence: MC009, MC024, MC050, MC052, MC081–MC086; MCL028, MCL042–MCL046, MCL052–MCL054; DA001–DA032.

## Integrating by replacement

A tuned identity is replaced by stock prose, or a selected visual specimen is regenerated wholesale to change one feature. Repair names what survives, what changes, and what is intentionally untouched. Evidence: MC031, MC050, MC053, MC064; MCL043, MCL045, MCL050, MCL054.

## Artifact and framework sprawl

Research, generation, or system-building leaves multiple apps, reports, workflows, and abstractions when one canonical continuation object or proven path would suffice. Cleanup must distinguish source, current artifact, derivative, scratch, provenance, and recoverability. Evidence: CJ042, CJ059; MC004, MC026, MC042, MC046, MC051, MC055, MC067, MC090; E016, E019; AO003, AO036, AO057, AO065.

## Confident unsafe helpfulness

Warmth and optimization language can conceal unsupported medical, factual, API, or causal claims. High-stakes usefulness requires calibrated authority, current sources, explicit limits, and escalation; emotional resonance is not a correctness check. Evidence: CJ079, CJ084–CJ085, CJ088–CJ089; MC005, MC079; MCL003–MCL004; AO043.
