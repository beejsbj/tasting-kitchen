# Audit and rewrite the recipe catalog by domain

Status: Ready for agent

Labels: `executor:codex`, `site:bjslab`

## Goal

Migrate the full recipe catalog to the approved authoring standard without a single worker skimming every domain.

## Context

The historical analysis remains valuable: it supplied the Mother's and Hybrid constraints, admired references, interaction grammars, design-system tendencies, motion preferences, conversation texture, agentic behavior, engineering work, and creative-code examples. The mistake is in how some of that material was packaged, not in doing the analysis.

## Done when

- this issue has parallel child issues for visual/UI/UX/motion, agentic/research/coding/tools, and conversation/journaling/thinking/writing/editing/music;
- every public recipe has a recognizable title, self-contained brief, deliverable, held constants, artifact type, defensible lineage, and private source rationale;
- Textbook recipes are conventional baseline tasks rather than disguised personal tensions;
- Mother's recipes clearly preserve a history-derived preference or unconventional grammar;
- Hybrid recipes clearly combine a baseline task with history-derived constraints;
- unnecessary correction turns are folded into the initial brief;
- duplicate or weak recipes are proposed for retirement rather than padded;
- catalog validation and tests pass.

## Constraints

- Depend on issue 02's proof slice.
- Preserve one primary domain per recipe; use tags for cross-domain behavior.
- Do not equalize recipe counts artificially.
- Any retirement of accepted seed dishes requires an explicit migration plan.
