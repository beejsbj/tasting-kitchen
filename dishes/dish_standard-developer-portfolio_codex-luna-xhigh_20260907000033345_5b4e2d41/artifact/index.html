01 / Websites / 2025

Cedar Classes

A community studio website that makes class descriptions, schedules and booking information easy to find.

Role
Frontend development and content structure, personal demonstration project
Stack
HTML · CSS · JavaScript

Problem

The fictional studio's class details were scattered across long pages, so a visitor had to hunt for the time, skill level and materials list.

Approach

I grouped classes into a consistent card structure and gave each class a detail section with its schedule, prerequisites and supplies. The small-screen navigation keeps the class list one tap away.

Result

The completed demonstration includes six class pages, responsive navigation and a local booking enquiry preview. There is no live booking service or measured conversion result.

Learning

Writing the content structure before choosing a layout helped keep the cards consistent without hiding useful detail.

This local case study is the available project material. A hosted demo and public repository are not available.

02 / Product UI / 2025

Stockroom Notes

A small inventory interface for recording supplies and flagging items that need attention.

Role
Frontend implementation, independent practice project
Stack
React · TypeScript · CSS

Problem

A fictional workshop needed a readable way to review stock counts without presenting every editing control at once.

Approach

I built a searchable table with clear stock states and a focused edit panel. Form labels, validation and keyboard focus were treated as part of the interface from the start.

Result

The prototype supports searching, editing local sample records and reviewing low-stock items. It has no backend, production users or published performance measurements.

Learning

Keeping the edit panel focused on one record made error messages easier to explain and test.

Read this local case study. The original prototype and its source are not publicly available.

03 / Websites / 2024

Fieldwork Journal

A reading-focused website for a fictional independent design journal.

Role
Frontend development from a self-written brief
Stack
HTML · CSS · JavaScript

Problem

The journal needed an article template that could handle short announcements and longer essays without separate layouts for every story.

Approach

I created a shared reading layout, article metadata and related-story links, then checked headings and line length at narrow and wide widths.

Result

The static demonstration contains an issue index and four sample articles. It is a portfolio exercise, with no audience or engagement figures claimed.

Learning

A restrained template gave the writing room and made inconsistent spacing much easier to spot.

The case study on this page is the supplied record. No external publication or repository link is available.
