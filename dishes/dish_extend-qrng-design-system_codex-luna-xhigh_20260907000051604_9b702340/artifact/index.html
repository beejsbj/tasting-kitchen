system notes / anatomy at a glance

One rough-edged grammar, four useful laws

Materials

Ink, paper, red field, yellow mark. The palette carries meaning, but status still gets a symbol and words.

Surface

  • hard border + crooked shadow
  • stamped heading strip
  • optional yellow kicker

States

  • rest / hover / active
  • visible keyboard focus
  • selected shape + label
  • reduced-motion safe

Ownership

The board owns its 50-number rule and fixed roll. The counter owns 1–10. Contexts coordinate the approval and receipt transition.
