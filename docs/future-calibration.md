# Future calibration — intentionally not implemented

The current project stops at analysis, assembled flights, and a reusable kitchen.

Later, after Burooj has accumulated real tastings naturally, those records could support a second bounded project: translating his comparative language into a compact, evidence-backed description of which model tendencies he prefers for which encounters. That might eventually become guidance such as “Burooj tends to prefer this model for UI reframing and another for careful operational recovery.”

That future work should begin from actual saved reactions and corrections, preserve uncertainty and counterexamples, distinguish harness effects from model tendencies, and avoid turning a few enjoyable results into universal rankings.

Nothing in version one performs ongoing ingestion, automatic preference inference, background monitoring, scoring, or skill generation.
